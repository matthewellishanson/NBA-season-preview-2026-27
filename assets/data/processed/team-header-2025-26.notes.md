# 2025–26 team-preview header data

`team-header-2025-26.js` is generated by joining two local inputs:

- `team-ratings-2016-2026.csv`, filtered explicitly to `season == 2025-26`. The displayed `ortg`, `drtg`, and `netrtg` fields and their matching rank fields are the unadjusted Basketball Reference values. The preparation does not use `*_adj`, `source_rank`, or `record_rank`.
- `../raw/nba-standings-2025-26.csv`, a compact transcription of the final, tiebreak-resolved conference order on the official [NBA 2025–26 regular-season standings](https://www.nba.com/standings?Season=2025-26), retrieved 2026-10-10. The local table retains the official team name, conference position, record, source URL, and retrieval date.

The script keys records by the preview’s stable team code and contains an explicit mapping among preview names/slugs, ratings names, and official standings names (notably `Los Angeles Clippers` versus `LA Clippers`). It verifies all 30 preview mappings, 30 unique ratings rows, 15 teams and positions 1–15 in each conference, complete numeric fields, rating ranks in 1–30, agreement between standings and ratings records, and the supplied San Antonio values.

Regenerate from the repository root with:

```powershell
python scripts/prepare_team_header_data.py
```

Ratings are rounded only for browser display. The generated asset retains the supplied source precision and rank ties.
